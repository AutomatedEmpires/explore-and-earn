# Brand Direction — Explore&Earn

> **Status:** Design-brain layer. This file defines *who Explore&Earn is* so every visual decision has a north star.
> **It does not redefine tokens or canon.** Foundations live in [`design-system-v1.md`](./design-system-v1.md), [`visual-language.md`](./visual-language.md), [`photo-language.md`](./photo-language.md). When this file and a founder-locked token doc disagree, the locked doc wins — flag the gap.
> Read this together with [`visual-system.md`](./visual-system.md) (the *how*) and judge every result with [`page-scorecard.md`](./page-scorecard.md).

---

## 1. One-sentence identity

**Explore&Earn is the premium field guide to working the world's seasons** — a marketplace where the housing, the meals, and the pay are promised up front, and the whole experience feels like the start of an adventure, not the filling-out of an application.

It is closer to **Patagonia × Airbnb × National Geographic** than to Indeed, ZipRecruiter, Workday, or any ATS.

## 2. Product personality

Five traits. Everything we ship should be locatable on this list. If a screen expresses none of them, it is off-brand.

| Trait | Means in practice | Tells you to… |
|---|---|---|
| **Adventurous** | The work is somewhere real — a coast, an orchard, a ridge. We sell the *place* as much as the job. | Lead with large, warm, scenic imagery. Use map and location surfaces as first-class, not afterthoughts. |
| **Trustworthy** | Real people, real housing, honest pay. We earn belief, we don't decorate it. | Make Verified-Host, the HOUSING/MEALS/PAY triad, and "Self-Declared by Host" qualifiers visible and legible. Never fake premium with decoration. |
| **Crafted (field-journal)** | Hand-drawn edges, paper surfaces, ink lines, Manrope-bold display. It feels made by hand, by people who do this. | Honor borders-first + the hand-drawn frame language. Resist clean corporate flatness *and* random gradient gloss. |
| **Warm** | People sleep, eat, and earn here. It's human and seasonal, not a transaction log. | Warm paper base, golden-hour imagery, plain human copy. Avoid gray-on-gray admin coldness. |
| **Operationally serious** | Seekers and hosts make money and life decisions here. It must be fast, clear, and dependable. | Strong hierarchy, scannable blocks, honest empty/error/loading states. Premium ≠ slow or precious. |

**The tension to hold:** *crafted + warm* pulls toward sketchbook; *operationally serious* pulls toward product. The magic is the **hybrid** — a field journal that happens to be an excellent app. Lose either pole and it fails: all-journal = twee and unusable; all-product = the generic SaaS the founder explicitly rejects.

## 3. Emotional target — what the user should feel

| Surface | First feeling (0.5s) | Held feeling (10s) |
|---|---|---|
| Homepage / marketing | "Whoa — I could *go* there." Wonder + wanderlust. | "And it's real — housing, meals, pay are right there. I'm in." |
| Seeker dashboard | "This is *mine* — it knows where I'm headed." Momentum. | "I know exactly my next move." Calm control. |
| Listing / discovery card | "That's beautiful. Tell me more." Pull. | "I trust this. Apply." Confidence. |
| Host dashboard | "I'm running something real." Command. | "I can see what needs me and act." Competence. |
| Community | "There are people like me doing this." Belonging. | "I want to post / go too." Participation. |

If a surface produces *neutrality* — "this is a form / a table / a dashboard" — it has failed the emotional target, regardless of how functional it is.

## 4. What "premium" means *for this app specifically*

Premium here is **not** glassmorphism, not dark-mode neon, not a drop-shadow card stack, not a tasteful gray SaaS panel. Those are other brands' premium. Ours is:

- **Premium photography, framed like a keepsake.** The single biggest lever. Large, warm, real scenic work imagery inside a hand-drawn frame + paper mat — never a filter painted *on* the photo. (See [`photo-language.md`](./photo-language.md).)
- **Editorial restraint.** Generous whitespace, one dominant element per module, type doing the talking. Richness comes from imagery + hierarchy, not from adding more chrome.
- **Material honesty.** Paper, ink, hand-drawn line, gold leaf for the special. It reads as *made*, not *generated*.
- **Earned trust signals.** The triad and verification aren't badges sprinkled for decoration; they're the product's core promise, designed to be believed.
- **Motion that feels physical.** Things slide, settle, and reveal like real objects (see [`motion-system.md`](./motion-system.md)) — never bounce, sparkle, or animate for its own sake.

**Litmus test:** *Could this screen hang in a Patagonia store or open a National Geographic feature?* If it could only live in a B2B SaaS marketing site, it's wrong.

## 5. How Explore&Earn differs from a normal job board

| Normal job board | Explore&Earn |
|---|---|
| Text-first list of roles | **Image-first set of places** |
| "Perks" buried in a bullet list | **HOUSING / MEALS / PAY** as a sacred, first-class triad — never collapsed to "Perks" |
| Location = a filter dropdown | **Location = a feeling and a map surface** you explore |
| Profile = a résumé to submit | **Profile = a journey** (where you've been, where you're headed, readiness) |
| Trust = a logo wall | **Trust = verified hosts + honest, qualified claims** |
| Dense corporate tables | **Cards with depth, rails, and scenic heroes** |
| Neutral, interchangeable, forgettable | **Specific, warm, unmistakably Explore&Earn** |

## 6. References (extract principles, never copy)

- **Patagonia / Filson / REI Co-op journal** — earthy premium, real people working outdoors, editorial typography, environmental seriousness. *Steal:* warmth + craft + restraint.
- **Airbnb** — large imagery, trust scaffolding, location-led discovery, friendly-but-serious product. *Steal:* card systems, map+list duality, trust UX.
- **National Geographic / field-guide books** — cinematic photography, captioned authority, sense of place and expedition. *Steal:* hero-as-thesis, editorial captions, wonder.
- **Premium travel apps (Hopper-class) for motion** — physical sheets, momentum, confident state changes. *Steal:* motion that feels like objects, not effects.

**Do not** drift toward: alpine-only adventure (the Farm/greenhouse "warm working landscape" lane is co-equal — balance imagery across all five lanes), generic startup gradient heroes, or the three AI-default looks (cream+serif+terracotta; near-black+acid accent; broadsheet hairlines).

## 7. Hard "do not" list (brand-level)

- ❌ Generic SaaS / admin / ATS layouts; dense corporate tables as a primary surface.
- ❌ Flat gray cards, weak white-card stacks, drop-shadow-heavy "depth."
- ❌ Random or off-palette gradients; "fake premium" decoration with no job.
- ❌ Filters/overlays painted onto host photos (frame *around*, never *on*).
- ❌ Color-only status; tiny text everywhere; cheap icon spam; mixed icon libraries.
- ❌ Collapsing HOUSING/MEALS/PAY into "Perks."
- ❌ Inventing color/type/spacing outside the locked tokens.
- ❌ Making it *only* alpine adventure and forgetting farms, coasts, and remote.

## 8. Voice (copy is design material)

Plain, warm, specific, confident. Write from the user's side of the screen.

- Name things by what the person controls ("Saved places," not "Saved entities").
- Active verbs on actions; the verb survives the whole flow ("Apply" → "Applied").
- Empty states are invitations, not apologies. Errors say what happened and how to fix it, in the product's voice.
- Specific beats clever. "Sleeps 2, meals included, $640/wk" beats "Great perks await."
