## ⚠️ Canonical repository

This repository — **`AutomatedEmpires/explore-and-earn`** — is the single
canonical codebase for Explore & Earn. **Never** write to
`AutomatedEmpires/exploreandearnv2`; it is deprecated and slated for deletion.

See the root [`AGENTS.md`](../AGENTS.md) for the full working agreement.

## Roles

Role-specific playbooks live in this folder:

- `product-manager.md` — scope, specs, acceptance criteria
- `ux-designer.md` — flows, surfaces, design system
- `frontend-engineer.md` — React/TS app surfaces
- `backend-engineer.md` — APIs, edge functions, business logic
- `database-engineer.md` — Postgres schema, RLS, migrations, RPCs
- `devops-engineer.md` — CI/CD, environments, observability

Each playbook must conform to the canonical Notion specs (Explore & Earn hub →
Master Index).
